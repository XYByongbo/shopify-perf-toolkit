# 02 资源决策表

任务 ID：待填写；范围：整站 / 单图 / 组件。仅列本次目标及受影响依赖；不要求局部任务盘点全站。基线记录：[01 基线表](01-baseline.md)。

一项资源一个 ID。体积、执行成本分别记录来源，不能仅按大小决定延迟。静态 `candidate` 表示待验证的源码候选，不等于已发生的运行问题或已证明收益。
